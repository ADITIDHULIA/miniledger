# 2–3 minute screen-recording checklist

Record the phone screen (or emulator) with the API terminal visible on the side if you can.

1. **0:00 – Intro (10s)** — "MiniLedger helps you track money you've lent to friends."
2. **0:10 – Login (30s)** — enter a phone number → Send OTP → switch to the API terminal and point at the printed OTP → type it in. Optionally show a wrong OTP error first.
3. **0:40 – Dashboard (20s)** — point at the summary card (Total lent / Repaid / Overdue), the recent list, and the red/orange overdue card.
4. **1:00 – Add loan (40s)** — tap Add loan → press Save with empty fields to show inline errors → fill name, amount, pick a due date, add a note, attach a receipt photo → Save → success toast → back on the dashboard, summary has updated.
5. **1:40 – Filters + details (25s)** — View all → tap Pending / Overdue / Repaid chips → open a loan to show details and receipt.
6. **2:05 – Mark repaid (25s)** — tap Mark as repaid → confirm → green "Repaid" badge → show the Overdue amount went down on the dashboard.
7. **2:30 – Logout (10s)** — log out, show you're back on the login screen. (Optional: mention the 32 backend tests.)
